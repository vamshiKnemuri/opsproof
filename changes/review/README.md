# OOM remediation review proposal

This lab-scoped GitOps patch raises the `opsproof-lab/opsproof-app` memory limit from 32 MiB to 128 MiB after an observed OOM kill. The proposal was generated by the deterministic mock agent and passed the typed-action policy gate.

[Private Kind CI run #11](https://github.com/vamshiKnemuri/opsproof/actions/runs/36050742822) verified zero available replicas before the change, one after, 6.10 seconds from action to readiness, no recorded side effects, an unavailable incident state after rollback, and readiness restored after reapplying the remediation. The checked [OOM evidence report](../../reports/sample/kind/oom.json) contains the observations, policy decision, measurements, change diff, rollback result, and trace.

This patch only targets the isolated lab namespace. It is a human-review example, not a production deployment. Any production GitOps change requires separate scope, evidence, and approval in the real target repository. No real-model trial is claimed.
